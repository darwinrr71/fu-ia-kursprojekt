# Granska kod

1. Läs kraven och `docs/standard.md`.
2. Granska endast de berörda kodändringarna.
3. Identifiera säkerhetsbrister, strukturproblem och brott mot kodstandarden.
4. Ange fil, rad, problem och konsekvens.
5. Beskriv vilken kontroll som kan upptäcka felet.
6. Skilj verifierade problem från misstänkta problem.
7. Föreslå förbättringar utan att ändra koden.

## Redovisning

Sammanfatta problem, allvarlighetsgrad, evidens och återstående risker.

Ändra inga filer och skapa inga commits utan godkännande.
