# TDD – Testdriven utveckling

1. Läs relevanta krav och `docs/standard.md`.
2. Identifiera vilket beteende som ska testas.
3. RED: Skriv ett test som beskriver beteendet och visa att det misslyckas.
4. GREEN: Skriv minsta möjliga kod som gör testet grönt.
5. REFACTOR: Förbättra koden utan att ändra beteendet.
6. Kör `npm test`, `npm run lint`, `npm run typecheck` och `npm run format:check`.
7. Ta aldrig bort, hoppa över eller inaktivera tester för att få grönt resultat.
8. Stoppa arbetet om oväntade fel uppstår och redovisa orsaken.

## Redovisning

Ange:

- Vilka filer som ändrades.
- Testresultat för RED och GREEN.
- Resultat från slutkontrollerna.
- Eventuella problem och återstående arbete.

Ändra inte orelaterade filer och skapa inga commits utan godkännande.
